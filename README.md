# Raw2SDTM-Mapper
From eCRF Mapping to SDTM Compliance: A Conservative Natural Language Processing-Based Workflow

This repository contains the workflow to:
- Automatically map terms from the EDC (PheedIt, Viedoc) of clinical data into SDTM-compliant variables (SDTMIG v3.4)
- Collect Metadata from different sources to generate a Specification File for each SDTM Module

The behavior is described inside each Jupyter Notebook, one per purpose.

Please, consider installing the requirements and dependencies as described in the requirements.txt file.
